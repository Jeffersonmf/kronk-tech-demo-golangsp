---------------------------------------------------------------
ATALHOS MENTAIS (decorar isso, não os comandos inteiros)
---------------------------------------------------------------

- ngpu-layers: 0 = TODAS as camadas na GPU (convenção invertida!)
- model_config.yaml fica em ~/.kronk/models/model_config.yaml (fora do repo)
- Kronk fala MCP nativo na porta 9000 (não confundir com 9001/9002, que são os NOSSOS)
- reasoning_effort vai na chamada da API (low/medium/high), não no YAML
- Se o Cline "não vê" um MCP: confirmar "type": "streamableHttp" no
  cline_mcp_settings.json (não "sse" — os dois servidores usam Streamable HTTP)
